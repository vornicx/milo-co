# Pupit & Co · v2 Apple

La vida, en buena compañía. Accesorios para disfrutar de paseos con perros; el dispensador 3 en 1 es el primer producto.

## Dirección visual

| Uso | Color |
| --- | --- |
| Fondo | Crema `#F7F5F0` |
| Texto, botones y capítulo de colores | Negro `#181818` |
| Panel de agua | Azul `#DCEEF5` |
| Panel de comida | Rosa `#F1DDE3` |
| Punto de marca | Naranja `#F07945` |

Páginas de producto de Apple como referencia de composición: titulares grandes centrados, objetos aislados, cabecera compacta, píldoras y espacios amplios. Sans del sistema con Helvetica Neue/Arial de respaldo. La crema y el acento naranja mantienen la identidad Pupit; los halos de azul y rosa acompañan al producto.

La portada sigue: producto dúo → tres funciones → elección de color sobre negro → idea de marca y fotografía de paseo → lista de espera → pie. Evitar tarjetas repetidas, tipografía serif y decoraciones de huesos o huellas.

## Interacción

El explorador tiene estados Agua, Comida y Residuos; cambia fotografía, cifra, texto y superficie. El selector de color cambia el render, el texto y la preferencia del formulario. La navegación estrecha usa un diálogo nativo con cierre mediante Escape. Las apariciones y cambios de estado respetan `prefers-reduced-motion`.

En 390 px, cabecera compacta, titular de dos líneas, llamadas apiladas, dúo completo, panel de funciones y producto en una columna. La lista y el pie mantienen lectura y controles utilizables sin desbordamiento.
